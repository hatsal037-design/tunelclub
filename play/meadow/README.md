# 오늘의 잔디밭 — 어른이 놀이터 행사 현장 페이지

2026-09-24 햇살님 «투넬 가입 → 코드 주면 잔디밭에 들어와서, 행사 진행하면서 같이 할 것들 · 공지 · 채팅 · 사진 올리기 · 투표 · 일정표 · 조 짜기(잘 섞이게 랜덤) 싹 다 구현해 봐».
코덱스 초안(입장 코드·사진·사진 투표·뒤풀이 조, 운영 DB 적용됨) 위에 Claude 가 이어 지었다. 초안 원본은 `tunelapp/보관/meadow_코덱스초안_2026-09-24/`.

## 들어오는 길
놀이터 페이지 «잔디밭» 탭 → «잔디밭 들어가기» → 카카오 로그인 → (투넬 닉네임 없으면 가입 안내) → 입장 코드 → 잔디밭.
운영진(관리자·운영진 역할)은 코드 없이 «운영진으로 바로 들어가기».

## 탭
| 탭 | 누구나 | 운영진 |
|---|---|---|
| 지금 | 최신 공지 · 지금 하는 순서/다음 순서 · 내 조 · 오늘 온 사람 · 뒤풀이 남아요 | |
| 일정 | 오늘 순서(지난 것 흐리게, 지금 표시) · 조 목록 | |
| 이야기 | 참가자 채팅(3초마다 새 글), 내 글 지우기 | 아무 글 지우기 |
| 사진 | 올리기(투표 출품 선택, 크기 줄이고 위치정보 제거 — 동의 체크는 없다. 참가자끼리만 보는 곳이라, «먼저 물어보기»는 개인 SNS 등 밖으로 가져갈 때의 약속으로 안내만 한다) · 사진첩 · 크게 보기 | 아무 사진 내리기 |
| 투표 | 오늘의 사진(한 표, 바꾸기 가능) · 마피아 MVP(나 빼고 한 표) — 경품 이름은 화면에 안 쓴다(햇살님 2026-09-25) | 공개 전에도 순위가 보임 |
| 운영 | — | 입장 코드 만들기·입장 받기 · 공지 · 지금 순서 · 순서 고치기 · 조 섞기 · 투표 열기/결과 공개 · 뒤풀이 조 · 참가자 내보내기 |

조 섞기: 조 개수 또는 한 조 인원을 정하면 수백 번 섞어 «앞서 같은 조였던 짝»이 제일 적은 안을 고른다(`model.js` mixTeams).
미리보기로 보고 «이대로 모두에게 보이기» 를 눌러야 참가자 화면에 뜬다. 20명 4조를 두 번째로 섞으면 겹침 4쌍이 수학적 최소다.

## 미리보기
`tunelapp/잔디밭_미리보기.command` 더블클릭 — 가짜 데이터(운영진 화면). 위 까만 띠에서 참가자 화면으로 바꿀 수 있다.
주소로는 `play/meadow/?demo=1`(운영진) · `?demo=guest`(참가자). 서버에 아무것도 안 보낸다.

## 켜는 순서 (햇살님 확인 뒤)
1. 서버: `bash 개발/sql/돌리기.sh 앱/play/sql/meadow_v2.sql` — v1 위에 칸·표만 더한다(지우는 것 없음).
   운영 DB 에서 되돌리는 트랜잭션으로 19가지 동작을 시험해 통과했다(채팅·1초 제한·코드 입장·MVP 자기 투표 막기·운영진 전용·조 중복 막기 등).
2. 앱: 커밋·푸시(«올려»). `play/meadow/`, `play/index.html`(잔디밭 탭 입장 버튼), `play/sql/`.
3. 당일: 운영 탭에서 입장 코드 만들기 → 현장에서 불러 주기.

## 넣지 않은 것
- 좋알람 — 플랫폼 규칙(5회 이상 참석)이라 1회 행사에서는 켤 사람이 없다.
- 실시간 푸시 — 3초(이야기)·12초(나머지) 간격으로 새로 받는다.
